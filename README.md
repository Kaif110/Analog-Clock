# 🕒 Analog Clock

A real-time analog clock built using **HTML, CSS, and JavaScript**. It displays the current time with rotating hour, minute, and second hands in a clean and minimal design.

## ✨ Features

- 🕒 Real-time clock functionality
- ⏱️ Hour, minute, and second hands
- 🔄 Automatically updates every second
- 🎨 Clean and minimal user interface
- 📱 Responsive design
- ⚡ Lightweight and easy to use

## 🛠️ Technologies Used

- **HTML5** – Structure of the clock
- **CSS3** – Clock design, styling, and hand positioning
- **JavaScript** – Real-time time calculation and rotation of clock hands
